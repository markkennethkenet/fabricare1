# Fabricare Development Skill

## Purpose
Help develop, debug, and maintain the Fabricare Flutter application.

## Guidelines
- Follow the existing Fabricare project structure.
- Use clean and readable Dart code.
- Reuse existing components and services.
- Keep business logic organized.
- Validate user inputs.
- Do not modify unrelated files.

## Workflow
1. Inspect the relevant Fabricare files.
2. Understand the existing implementation.
3. Implement the requested feature.
4. Run flutter analyze.
5. Run the application.
6. Test the affected functionality.
