# Fabricare UI Skill

## Purpose
Develop and maintain the user interface of the Fabricare Flutter application.

## Guidelines
- Use Flutter and Dart.
- Follow Fabricare's existing design.
- Create reusable widgets.
- Keep the interface responsive.
- Maintain consistent colors, typography, spacing, and navigation.
- Do not modify unrelated features.

## Workflow
1. Inspect the existing Fabricare UI.
2. Identify the requested change.
3. Implement the UI.
4. Test the screen on Flutter.
5. Check for layout and UI errors.
