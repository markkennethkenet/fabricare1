# Fabricare UI Skill

## Purpose
Guide the development of consistent, usable, and maintainable Flutter screens for Fabricare.

## Before Making Changes
- Read knowledge.md and AGENTS.md.
- Inspect existing screens, widgets, and navigation.
- Identify reusable UI components.
- Understand the requested behavior before editing.

## UI Guidelines
- Follow existing Flutter and Dart conventions.
- Reuse existing widgets when appropriate.
- Maintain consistent layouts, spacing, and typography.
- Consider different screen sizes and keyboard behavior.
- Provide appropriate loading, empty, success, and error states.
- Consider accessibility and readable text.
- Avoid changing unrelated screens or features.

## Validation
- Check relevant navigation and user interactions.
- Test input validation and error handling.
- Run available Flutter analysis and tests when appropriate.
- Report issues that could affect usability.

## Completion Report
Summarize UI changes, modified files, checks performed, and remaining issues.
