# Fabricare Development Skill

## Purpose
Help implement and maintain features in the existing Fabricare capstone project.

## Before Making Changes
- Read knowledge.md and AGENTS.md.
- Inspect the existing implementation before editing.
- Identify affected Flutter, Python, and database files.
- Preserve existing developer changes.

## Development Guidelines
- Follow the existing architecture and coding conventions.
- Reuse existing components, services, and utilities.
- Validate inputs and handle errors appropriately.
- Preserve existing API contracts and database compatibility.
- Never expose passwords, tokens, or environment secrets.
- Avoid unnecessary dependencies and unrelated refactoring.

## Testing
- Review available Flutter and Python tests.
- Test changed functionality and relevant failure cases.
- Report actual test results honestly.

## Completion Report
Summarize modified files, implementation decisions, tests performed, and remaining issues.
